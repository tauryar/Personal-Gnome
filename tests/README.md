# Testler

Uygulama eklendiğinde test kodunu ve küçük örnek girdileri bu klasörde tutun. Testleri çalıştıran komutu, gerekli araçları ve başarı ölçütünü burada belgeleyin.

| Test türü | Örnek kapsam |
| --- | --- |
| Birim testi | Bir fonksiyonun geçerli, sınırda veya hatalı girdideki davranışı |
| Entegrasyon testi | Birden fazla bileşenin birlikte beklenen sonucu üretmesi |
| Başlangıç testi | Uygulamanın örnek ayarlarla açılması ve temel işlemi tamamlaması |

Bir hata düzeltilirken, mevcut testler hatayı yakalamıyorsa hata tekrarlandığında başarısız olacak bir test ekleyin.
