# Kullanım örnekleri

Uygulama eklendiğinde örnek girdileri, beklenen çıktıları ve baştan sona çalıştırma komutlarını buraya koyun. Her örneğin kullandığı ayarları ve beklenen sonucu belirtin.

İlk dokümantasyon değişikliğini gösteren örnek, Git paketindeki `feature/dokuman-ornegi` dalında `examples/ilk-degisiklik.md` dosyasında yer alır.
