# Komut dosyaları

Kurulum, doğrulama ve bakım gibi tekrarlanan proje işlemlerinin komut dosyalarını bu klasöre ekleyin. Her dosyanın hangi işletim sisteminde, hangi klasörden ve hangi parametrelerle çalıştırıldığını burada kaydedin.

| Kayıt | İçerik |
| --- | --- |
| Çalıştırma | Repo kökünden kopyalanıp çalıştırılabilen komut |
| Girdi | Gerekli dosyalar, parametreler ve ortam ayarları |
| Çıktı | Yazılan dosyalar ile başarı ve hata durumları |
