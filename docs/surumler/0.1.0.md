# 0.1.0 sürüm notu

Bu sürüm adayı, proje dosya yapısını ve Git çalışma akışını içerir. İlk kurulum için ana `README.md` dosyasındaki Git paketi ve ZIP seçeneklerini kullanabilirsiniz. [Başlangıç rehberi](../../README.md)

## İçerik

- Kaynak, test, örnek, yapılandırma ve komut dosyaları için açıklamalı klasörler.
- Proje tanımı ve mimari kaydı şablonları.
- Dal adları, inceleme isteği ve sürüm hazırlama adımları.
- Geliştirmeyi başlatmak için örnek iş listesi. [Yol haritası](../yol-haritasi.md)

## Sürüm doğrulaması

Git paketinden açılan kopyada yerel dalları kurduktan sonra aşağıdaki komutları çalıştırın.

```console
git diff --name-status develop..release/0.1.0
git diff --check develop..release/0.1.0
```

Dosya listesinde `CHANGELOG.md` değişikliği ve bu sürüm notunun eklenmesi görünür. Boşluk kontrolü başarılı olduğunda ikinci komut çıktı üretmez. Birleştirme ve etiketleme sırası için [Git çalışma akışını](../git-akisi.md) izleyin.
